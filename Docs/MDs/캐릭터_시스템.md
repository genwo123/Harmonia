# 🎮 캐릭터 시스템

> 플레이어와 NPC의 기본 구조

---

## 📌 개요

Harmonia는 **1인칭 시점** 게임으로, 플레이어 캐릭터(Noah)와 NPC(Unia)로 구성됩니다.  
Enhanced Input System을 사용하며, AI는 Behavior Tree로 구현했습니다.

---

## 🎮 주요 캐릭터

---

### 🔷 플레이어 캐릭터 (Noah)

![플레이어](../Image/System/Player/player_main.png)

**1인칭 퍼즐 게임 플레이어**

플레이어는 레이저 퍼즐을 풀고 오브젝트와 상호작용하며 게임을 진행합니다.

**기본 구조:**
```cpp
ACharacter (Unreal Base)
    ↓
AHamoniaCharacter (C++)
    ├─ Enhanced Input Component
    ├─ Camera Component (1인칭)
    ├─ Interaction Component
    ├─ Inventory Component
    └─ Dialogue Manager Component
```

**주요 기능:**
- 이동 (걷기, 달리기)
- 상호작용 (E키)
- 오브젝트 파밍 (들기/놓기)
- 인벤토리 관리 (Tab)

**📖 상세 보기:** [플레이어 상호작용 →](./System/Player/상호작용_시스템.md)

---

### 🔷 NPC - Unia

![Unia](../Image/System/NPC/unia_main.png)

**플레이어를 따라다니는 로봇 NPC**

Unia는 스토리 진행과 힌트 제공을 담당하는 AI 캐릭터입니다.

**기본 구조:**
```cpp
ACharacter (Unreal Base)
    ↓
AUnia (C++)
    ├─ UniaAIController (C++)
    │   └─ Behavior Tree
    ├─ Interaction Sphere
    └─ Dialogue Manager Component
```

**주요 기능:**
- 플레이어 추종 (AI)
- 대화 상호작용 (E키)
- 특정 지점 이동
- 플레이어 바라보기

**기술 스택:** `C++` `AI Controller` `Behavior Tree`

**📖 상세 보기:** [Unia 시스템 →](./System/NPC/Unia_시스템.md)

### 입력 시스템 (Enhanced Input)

![입력 시스템](../Image/System/Player/input_system.png)

**언리얼 5 Enhanced Input 사용**

```cpp
// Input Actions
UInputAction* MoveAction;
UInputAction* LookAction;
UInputAction* InteractAction;
UInputAction* SprintAction;
UInputAction* InventoryAction;
```

**입력 매핑:**

| 입력 | 액션 | 기능 |
|------|------|------|
| **WASD** | Move | 이동 |
| **마우스** | Look | 카메라 회전 |
| **E** | Interact | 상호작용 |
| **Shift** | Sprint | 달리기 |
| **Tab** | Inventory | 인벤토리 열기 |
| **R** | Push | 받침대 밀기 |
| **Z** | Reset | 퍼즐 리셋 |

---

### 이동 시스템

**기본 이동:**
- 걷기: 400 units/s
- 달리기: 600 units/s
- 점프: 가능 (높이 조정 가능)

**특징:**
- 1인칭 시점 (손 모델 없음)
- 간단한 이동만 구현 (크라우치 없음)

### 상호작용 시스템

**레이캐스트 기반 상호작용**

```cpp
void AHamoniaCharacter::CheckInteraction()
{
    FHitResult Hit;
    FVector Start = Camera->GetComponentLocation();
    FVector End = Start + Camera->GetForwardVector() * InteractionDistance;
    
    if (GetWorld()->LineTraceSingleByChannel(Hit, Start, End, ECC_Visibility))
    {
        if (AActor* HitActor = Hit.GetActor())
        {
            if (HitActor->Implements<UInteractableInterface>())
            {
                // 상호작용 가능 표시
                CurrentInteractable = HitActor;
            }
        }
    }
}
```

**상호작용 거리:** 200cm (기본)

**📖 상세 보기:** [상호작용 시스템 →](./상호작용_시스템.md)

### 오브젝트 파밍

**한 번에 하나의 오브젝트만**

퍼즐 오브젝트를 들고 다니며 받침대에 배치할 수 있습니다.

```cpp
void AHamoniaCharacter::PickupObject(AActor* Object)
{
    // 현재 들고 있는 오브젝트가 있으면 불가
    if (HeldObject) return;
    
    HeldObject = Object;
    Object->AttachToComponent(HeldObjectAttachPoint, ...);
}
```

**조작:**
- **E키 (오브젝트):** 들기/놓기
- **E키 (받침대):** 오브젝트 부착/탈착
- **R키 (받침대):** 밀기
- **E키 회전 (받침대):** 45° 회전

**📖 상세 보기:** [오브젝트 파밍 →](./System/Player/오브젝트_파밍.md)

## 🤖 Unia AI 시스템

---

### AI Controller

```cpp
AUniaAIController (C++)
    ├─ Behavior Tree Asset
    ├─ Blackboard Asset
    └─ AI Perception Component
```

**Blackboard Keys:**
- `PlayerPawn` (Object) - 플레이어 참조
- `bCanFollow` (Bool) - 추종 가능 여부
- `FollowDistance` (Float) - 추종 거리
- `TargetLocation` (Vector) - 목표 지점

---

### Behavior Tree 구조

```
Root
├─ Sequence (대화 중?)
│   └─ Wait (대화 종료까지)
│
├─ Selector (추종 모드)
│   ├─ Sequence (거리 체크)
│   │   ├─ 거리 > 1500cm?
│   │   └─ Teleport Behind Player
│   │
│   └─ Sequence (일반 추종)
│       ├─ 거리 > 400cm?
│       └─ Move To Player
│
└─ Wait at Location
```

**주요 기능:**
- **거리 체크:** 플레이어와 거리 계산
- **추종:** 일정 거리 이상일 때 따라감
- **텔레포트:** 너무 멀어지면 뒤로 순간이동
- **대기:** 대화 중이거나 특정 지점에서 대기

---

### 대화 상호작용

**Interaction Sphere 기반**

```cpp
// Unia.h
UPROPERTY(EditAnywhere)
USphereComponent* InteractionSphere;  // 반경 200cm

void AUnia::OnInteractionSphereBeginOverlap(...)
{
    if (AHamoniaCharacter* Player = Cast<AHamoniaCharacter>(OtherActor))
    {
        Player->SetCurrentInteractableNPC(this);
        bPlayerInRange = true;
    }
}
```

**E키 입력 시:**
1. 대화 위젯 생성
2. AI 추종 멈춤
3. 플레이어 바라보기
4. 대화 진행

**📖 상세 보기:** [대화 시스템 →](./대화_시스템.md)
