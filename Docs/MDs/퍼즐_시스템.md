# 🧩 퍼즐 시스템

> Harmonia의 핵심 게임플레이 메커니즘

---

## 📌 개요

Harmonia는 **RGB 색광 혼합**을 활용한 레이저 퍼즐 게임입니다.  
플레이어는 거울과 받침대를 이용해 레이저 경로를 조정하며 퍼즐을 해결합니다.

---

## 🎮 주요 퍼즐 시스템

---

### 🔷 레이저 퍼즐 (핵심!)

![레이저 시스템](../Image/System/Laser/laser_main.png)

**RGB 가산 혼합을 이용한 색 변환 퍼즐**

플레이어는 레이저를 반사/굴절/변환시켜 특정 색을 목표 지점에 도달시켜야 합니다.

**핵심 메커니즘:**
- 흰색 레이저 출발 → 컬러박스로 색 변환
- 거울/반사패널로 경로 조정
- 분광기로 2갈래 분리
- 목표 지점에 보색 도달 시 활성화 (Red + Cyan = White)

**기술 스택:** Blueprint (유튜브 참고 후 개조)

**📖 상세 보기:** [레이저 시스템 →](./System/Laser/레이저_시스템.md)

---

### 🔷 받침대 시스템

![받침대 시스템](../Image/System/Pedestal/pedestal_main.png)

**그리드 기반 이동/회전 시스템**

퍼즐 오브젝트를 부착하여 그리드 단위로 밀고 회전시킬 수 있습니다.

**조작 방법:**
- **R키:** 밀기 (상하좌우 그리드 이동)
- **E키:** 45° 회전
- 벽이나 다른 받침대에 막히면 이동 불가

**기술 스택:** `C++` `GridManager` `Blueprint`

**📖 상세 보기:** [받침대 시스템 →](./System/Pedestal/받침대_시스템.md)

---

### 🔷 베리타스 회로

![베리타스 회로](../Image/System/Puzzle/veritas_main.png)

**레이저 활성화를 위한 한붓그리기 퍼즐**

각 레벨의 레이저 분출구를 활성화하기 위해 반드시 해결해야 하는 퍼즐입니다.

**규칙:**
- 시작(녹색) → 도착(파란색)
- 필수 지점(노란색) 모두 방문
- 한 번 지나간 경로 재방문 불가
- 벽 충돌 시 리셋

**기술 스택:** `C++ UMG` `NativePaint()` `실시간 그리기`

**적용 레벨:** Level 1-6, 8-10

**📖 상세 보기:** [베리타스 회로 →](./System/Puzzle/베리타스_회로.md)

---

### 🔷 타자기 시스템

![타자기](../Image/System/Puzzle/typewriter_main.png)

**패스워드 입력 퍼즐 (Level 4-6 전용)**

레이저로 숨겨진 단어를 찾아 타자기에 입력하는 퍼즐입니다.

**플레이 흐름:**
```
레이저 → 벽 패널 네임태그 → 숨겨진 단어 표시
    ↓
노트에 자동 기록
    ↓
타자기에 패스워드 입력
    ↓
금고 해금 + RGB 코어 획득 + 문 열림
```

**특별 요소:**
- Level 4-6의 각 단어 첫 글자 → 최종 엔딩 패스워드 (7글자)

**기술 스택:** `Blueprint UMG` `키보드 입력`

**📖 상세 보기:** [타자기 시스템 →](./System/Puzzle/타자기_시스템.md)

---

### 🔷 복도 퍼즐

![복도 퍼즐](../Image/System/Puzzle/corridor_main.png)

**Level 7 특수 퍼즐 (RGB 코어 필요)**

RGB 코어 3개를 모두 획득한 후 진입 가능한 특수 퍼즐입니다.

**메커니즘:**
- 순차적 경로 기억 게임
- 타임어택 (실패 시 리셋)
- 클리어 시 하얀색 코어 획득 (미구현)

**기술 스택:** `Blueprint`

**📖 상세 보기:** [복도 퍼즐 →](./System/Puzzle/복도_퍼즐.md)

---

## 🎯 퍼즐 진행 흐름

```
레벨 시작
    ↓
베리타스 회로 풀기 (한붓그리기)
    ↓
레이저 분출구 활성화
    ↓
레이저 + 받침대로 본격 퍼즐
    ↓
목표 달성
    ↓
[Level 4-6만] 타자기 패스워드 입력
    ↓
문 열림 & 다음 레벨
```

## 📊 난이도 설계

| 레벨 | 주요 메커니즘 | 그리드 크기 | 난이도 |
|------|--------------|------------|--------|
| 1-3 | 튜토리얼 (거울, 받침대) | 작음 | ★☆☆☆☆ |
| 4-6 | 타자기 추가 | 중간 | ★★★☆☆ |
| 7 | 복도 퍼즐 (특수) | - | ★★★★☆ |
| 8-10 | 복합 퍼즐 | 큼 | ★★★★★ |

## 🔧 주요 퍼즐 오브젝트

| 오브젝트 | 각도 | 부착 위치 | 기능 |
|---------|------|----------|------|
| **거울** | 90°, 45° | 벽 전용 | 레이저 반사 |
| **반사패널** | 90°, 45° | 받침대 | 레이저 반사 (회전 가능) |
| **분광기** | 180°, 90°, 45° | 받침대 | 레이저 2갈래 분리 |
| **컬러박스** | - | 받침대 | 레이저 색 변환 |
| **받침대** | - | 그리드 | 오브젝트 부착/이동/회전 |

---

## 🎮 리셋 시스템 (Z키)

퍼즐 실패 시 언제든 리셋 가능합니다.

**리셋되는 것:**
- ✅ 베리타스 회로 → 재풀이 필요
- ✅ 받침대 위치 → 원위치
- ✅ 타자기 입력 → 초기화
- ✅ 레이저 상태 → 초기화

**리셋 안 되는 것:**
- ❌ 노트 내용 (한 번 해금하면 영구 보존)
