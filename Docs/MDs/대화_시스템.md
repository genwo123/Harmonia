# 💬 대화 시스템

> NPC 대화 및 스토리 진행 시스템

---

## 📌 개요

Harmonia의 대화 시스템은 **데이터 테이블 기반**으로 설계되었습니다.  
Unia와의 대화를 통해 스토리가 진행되며, 퀘스트 상태에 따라 대화 내용이 변화합니다.

---

## 🏗️ 시스템 구조

```cpp
DialogueManagerComponent (C++)
    ├─ Dialogue Data Table 로딩
    ├─ 조건 체크 (퀘스트, 서브스텝)
    ├─ 대화 진행 관리
    └─ 선택지 처리
    ↓
WBP_DialogueWidget (Blueprint UMG)
    ├─ 텍스트 표시
    ├─ 화자 이미지
    ├─ 선택지 버튼
    └─ 애니메이션
```

---

## 🔷 핵심 구조

---

### 1️⃣ DialogueManagerComponent (C++)

**대화 관리의 핵심 컴포넌트**

모든 캐릭터(플레이어, Unia)에 부착되어 대화를 관리합니다.

```cpp
UCLASS()
class UDialogueManagerComponent : public UActorComponent
{
    GENERATED_BODY()

public:
    // 대화 데이터 테이블
    UPROPERTY(EditAnywhere)
    UDataTable* DialogueDataTable;

    // 현재 대화 ID
    UPROPERTY(BlueprintReadWrite)
    FString CurrentDialogueID;

    // 대화 시작
    UFUNCTION(BlueprintCallable)
    bool StartDialogue(const FString& DialogueID);

    // 대화 진행
    UFUNCTION(BlueprintCallable)
    void ProgressDialogue();

    // 선택지 선택
    UFUNCTION(BlueprintCallable)
    void SelectChoice(int32 ChoiceIndex);

    // 조건 체크
    UFUNCTION(BlueprintCallable)
    bool CheckAllConditions(const FDialogueData& DialogueData);
};
```

**📖 상세 보기:** [DialogueManagerComponent 구현 →](소스코드)

### 2️⃣ FDialogueData (구조체)

**대화 데이터 구조**

```cpp
USTRUCT(BlueprintType)
struct FDialogueData : public FTableRowBase
{
    GENERATED_BODY()

    // 기본 정보
    UPROPERTY(EditAnywhere)
    FString DialogueID;             // 대화 고유 ID

    UPROPERTY(EditAnywhere)
    ESpeakerType Speaker;           // 화자 (Noah, Unia, System)

    UPROPERTY(EditAnywhere)
    FText DialogueText;             // 대화 내용

    UPROPERTY(EditAnywhere)
    FString NextDialogueID;         // 다음 대화 ID

    // 레벨 시스템
    UPROPERTY(EditAnywhere)
    FString LevelName;              // 대화가 발생하는 레벨

    UPROPERTY(EditAnywhere)
    int32 RequiredSubStep;          // 필요한 서브스텝 (-1 = 무관)

    UPROPERTY(EditAnywhere)
    bool bIsLevelEnd;               // 레벨 종료 대화?

    // 선택지
    UPROPERTY(EditAnywhere)
    bool bHasChoices;               // 선택지 있음?

    UPROPERTY(EditAnywhere)
    TArray<FString> ChoiceTexts;    // 선택지 텍스트

    UPROPERTY(EditAnywhere)
    TArray<FString> ChoiceTargetIDs; // 선택지별 다음 대화 ID

    // 기타
    UPROPERTY(EditAnywhere)
    float DisplayDuration;          // 자동 진행 시간 (0 = 수동)
};
```

## 🎮 대화 진행 방식

---

### 대화 시작

```
Player E키 (Unia)
    ↓
Unia::Interact_Implementation()
    ↓
OnUniaDialogueActivated.Broadcast(DialogueID, DataTable)
    ↓
Player DialogueManagerComponent::StartDialogue()
    ↓
Load Dialogue Data
    ↓
Show Dialogue Widget
    ↓
Set Input Mode UI Only
```

---

### 대화 진행

![대화 UI](../Image/System/dialogue_ui.png)

```
Dialogue Widget 표시
    ↓
Show Speaker & Text
    ↓
선택지 있음?
    ├─ Yes → Show Choice Buttons
    │           ↓
    │       Player Clicks Choice
    │           ↓
    │       Load Next Dialogue (ChoiceTargetID)
    │
    └─ No → Wait for Click or Auto Progress
                ↓
            Load Next Dialogue (NextDialogueID)
    ↓
NextDialogueID가 비어있음?
    ├─ Yes → End Dialogue
    └─ No → Continue
```

## 🎯 레벨 기반 대화

### 퀘스트 진행에 따른 대화

```cpp
bool UDialogueManagerComponent::CanProgressToDialogue(const FString& DialogueID)
{
    FDialogueData* Data = GetDialogueData(DialogueID);
    
    // 레벨 체크
    if (Data->LevelName != CurrentLevelName)
        return false;
    
    // 서브스텝 체크
    if (Data->RequiredSubStep >= 0)
    {
        if (CurrentSubStep < Data->RequiredSubStep)
            return false;  // 아직 진행 불가
    }
    
    return true;
}
```

**대화 조건:**
- **레벨 일치:** 같은 레벨에서만 발생
- **서브스텝 완료:** 특정 단계 완료 후 대화 해금
- **레벨 종료 대화:** 모든 퍼즐 완료 후

---

### 레벨 종료 대화

```cpp
// bIsLevelEnd = true인 대화
if (DialogueData.bIsLevelEnd)
{
    // 레벨 완료 처리
    OnLevelDialogueEnded();
    
    // 다음 레벨로 진행 가능
    UnlockNextLevel();
}
```

## 🔷 선택지 시스템

### 분기형 대화

```cpp
// 선택지가 있는 대화
if (DialogueData.bHasChoices)
{
    // 선택지 버튼 생성
    for (int32 i = 0; i < DialogueData.ChoiceTexts.Num(); i++)
    {
        CreateChoiceButton(DialogueData.ChoiceTexts[i], i);
    }
}

// 선택 시
void SelectChoice(int32 ChoiceIndex)
{
    FString NextID = DialogueData.ChoiceTargetIDs[ChoiceIndex];
    StartDialogue(NextID);
}
```

**사용 예:**
- 엔딩 선택 (Unia 희생 vs 탈출)
- 힌트 받기 vs 스스로 풀기

### 대화 상태 저장

```cpp
// GameInstance에 저장
void SaveDialogueState()
{
    SaveData->CurrentDialogueID = CurrentDialogueID;
    SaveData->CompletedDialogues.Add(CurrentDialogueID);
    SaveData->LevelDialogueEnded = bLevelDialogueEnded;
}
```
