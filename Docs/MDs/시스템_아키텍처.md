# 🏗️ 시스템 아키텍처

> Harmonia 프로젝트의 전체 시스템 구조

---

## 📌 개요

Harmonia는 **C++와 Blueprint를 혼합**하여 개발한 1인칭 퍼즐 게임입니다.  
기반 시스템은 C++로, 게임플레이와 비주얼 요소는 Blueprint로 구현했습니다.

---

## 🎯 개발 철학

### C++ vs Blueprint 역할 분담

```
C++ 구현:
- 핵심 시스템 (상호작용, 그리드)
- 성능 중요 부분 (실시간 그리기)
- 재사용 가능한 베이스 클래스

Blueprint 구현:
- 게임플레이 로직 (레이저, 퍼즐)
- 비주얼 요소
- 기획자/디자이너 작업 영역
```

---

## 🏛️ 전체 시스템 구조

```
Harmonia Project
│
├── Character System
│   ├── HamoniaCharacter (C++ - 플레이어)
│   └── Unia (C++ - NPC AI)
│
├── Interaction System (C++)
│   ├── InteractableInterface
│   ├── InteractableMechanism
│   └── PuzzleInteractionComponent
│
├── Puzzle System (혼합)
│   ├── Laser (Blueprint)
│   ├── Pedestal (C++ + BP)
│   │   └── GridManager (C++)
│   └── VeritasCircuit (C++ UMG)
│
├── UI System (혼합)
│   ├── C++ UMG
│   │   ├── UStrokeGrid (베리타스)
│   │   ├── TutorialWidget
│   │   └── HintWidget
│   └── Blueprint UMG
│       ├── Inventory
│       ├── Menu
│       └── Typewriter
│
├── Data System (C++)
│   ├── GameInstance
│   ├── SaveGame
│   └── DataTables
│
└── Dialogue System (C++ + BP)
    ├── DialogueManagerComponent (C++)
    └── DialogueWidget (BP)
```

### 1️⃣ 캐릭터 시스템

![캐릭터 구조](../Image/System/character_architecture.png)

**플레이어와 NPC의 기본 구조**

```cpp
ACharacter (Unreal Base)

│   └─ Inventory Component
│
└─ AUnia (NPC)
    ├─ AI Controller
    ├─ Behavior Tree
    └─ Dialogue Component
```

### 2️⃣ 상호작용 시스템 (C++)

![상호작용 구조](../Image/System/interaction_architecture.png)

**모든 상호작용의 기반 시스템**

```cpp
IInteractableInterface (인터페이스)
    ↓
AInteractableMechanism (액터)
    ├─ Door (문 열기)
    ├─ Keypad (키패드 입력)
    └─ Widget (UMG 띄우기)
    
UPuzzleInteractionComponent (컴포넌트)
    ├─ Pick Up (들기)
    ├─ Put Down (놓기)
    └─ Place On Pedestal (받침대 배치)
```

**주요 클래스:**
- `IInteractableInterface` - 상호작용 인터페이스
- `AInteractableMechanism` - 상호작용 액터
- `UPuzzleInteractionComponent` - 퍼즐 오브젝트 컴포넌트

**📖 상세 보기:** [상호작용 시스템 →](./상호작용_시스템.md)

## 🔧 주요 C++ 클래스

### 캐릭터
```cpp
AHamoniaCharacter          // 플레이어 캐릭터
AUnia                      // NPC (AI)
AHamoniaPlayerController   // 플레이어 컨트롤러
```

### 상호작용
```cpp
IInteractableInterface          // 상호작용 인터페이스
AInteractableMechanism          // 상호작용 액터
UPuzzleInteractionComponent     // 퍼즐 오브젝트 컴포넌트
```

### 퍼즐
```cpp
APedestal                  // 받침대
GridManager (Blueprint)    // 그리드 관리 (BP에서 구현)
```

### UI
```cpp
UStrokeGrid               // 베리타스 회로
UStrokeCell               // 베리타스 셀
UTutorialWidget           // 튜토리얼 팝업
UHintWidget               // 힌트 위젯
```

### 데이터
```cpp
UHamoina_GameInstance     // 게임 인스턴스
UHamonia_SaveGame         // 세이브 데이터
UDialogueManagerComponent // 대화 관리
```

## 📊 개발 비율

```
C++ 구현:        40%
Blueprint 구현:  50%
혼합:           10%
```

**주요 C++ 구현:**
- 캐릭터 기반 시스템
- 상호작용 시스템
- 그리드 시스템
- C++ UMG (베리타스, 튜토리얼 등)
- 데이터 관리

**주요 Blueprint 구현:**
- 레이저 시스템
- 퍼즐 메커니즘
- 일반 UI
- 레벨 스크립팅
