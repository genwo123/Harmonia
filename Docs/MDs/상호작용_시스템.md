# 🔗 상호작용 시스템

> 모든 오브젝트 상호작용의 기반 시스템

---

## 📌 개요

Harmonia의 상호작용 시스템은 **인터페이스 기반**으로 설계되었습니다.  
플레이어는 E키를 통해 다양한 오브젝트와 상호작용하며 퍼즐을 해결합니다.

---

## 🏗️ 시스템 구조

```cpp
IInteractableInterface (인터페이스)
    ↓
├─ AInteractableMechanism (액터)
│   ├─ Door (문 열기)
│   ├─ Keypad (키패드 입력)
│   ├─ Widget (UMG 띄우기)
│   └─ Puzzle Object (퍼즐 오브젝트)
│
├─ APedestal (받침대)
│   ├─ 오브젝트 부착/탈착
│   ├─ 밀기 (R키)
│   └─ 회전 (E키 회전)
│
└─ AUnia (NPC)
    └─ 대화 시작
```

---

## 🔷 핵심 클래스

---

### 1️⃣ IInteractableInterface

**모든 상호작용 오브젝트의 기본 인터페이스**

```cpp
UINTERFACE(Blueprintable)
class UInteractableInterface : public UInterface
{
    GENERATED_BODY()
};

class IInteractableInterface
{
    GENERATED_BODY()

public:
    // 상호작용 실행
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable)
    void Interact(AActor* Interactor);

    // 상호작용 가능 여부
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable)
    bool CanInteract(AActor* Interactor);

    // 상호작용 텍스트 (E키 프롬프트)
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable)
    FString GetInteractionText();

    // 상호작용 타입
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable)
    EInteractionType GetInteractionType();
};
```

**상호작용 타입:**
```cpp
enum class EInteractionType : uint8
{
    Default,    // 기본
    Pickup,     // 줍기
    Open,       // 열기
    Use,        // 사용
    Place,      // 놓기
    Rotate,     // 회전
    Push        // 밀기
};
```

**📖 상세 보기:** [플레이어 상호작용 →](./System/Player/상호작용_시스템.md)

### 2️⃣ AInteractableMechanism

**퍼즐 메커니즘의 기본 액터**

다양한 퍼즐 요소들의 베이스 클래스입니다.

```cpp
UCLASS()
class AInteractableMechanism : public AActor, public IInteractableInterface
{
    GENERATED_BODY()

public:
    // 메커니즘 타입
    UPROPERTY(EditAnywhere)
    EMechanismType MechanismType;

    // Components
    UPROPERTY(VisibleAnywhere)
    UStaticMeshComponent* MeshComponent;

    UPROPERTY(VisibleAnywhere)
    USphereComponent* InteractionSphere;

    // Interface 구현
    virtual void Interact_Implementation(AActor* Interactor) override;
    virtual bool CanInteract_Implementation(AActor* Interactor) override;
};
```

**메커니즘 타입:**
```cpp
enum class EMechanismType : uint8
{
    Door,      // 문
    Widget,    // UMG 위젯 (키패드, 베리타스 등)
    Puzzle     // 퍼즐 오브젝트
};
```

## 🎮 상호작용 방식

---

### 플레이어 감지 (레이캐스트)

![레이캐스트](../Image/System/interaction_raycast.png)

**매 프레임 카메라 중앙에서 레이캐스트**

```cpp
void AHamoniaCharacter::Tick(float DeltaTime)
{
    CheckForInteractable();
}

void AHamoniaCharacter::CheckForInteractable()
{
    FHitResult Hit;
    FVector Start = Camera->GetComponentLocation();
    FVector End = Start + Camera->GetForwardVector() * InteractionDistance;
    
    if (GetWorld()->LineTraceSingleByChannel(Hit, Start, End, ECC_Visibility))
    {
        AActor* HitActor = Hit.GetActor();
        
        if (HitActor && HitActor->Implements<UInteractableInterface>())
        {
            IInteractableInterface* Interactable = Cast<IInteractableInterface>(HitActor);
            
            if (Interactable->CanInteract(this))
            {
                CurrentInteractable = HitActor;
                ShowInteractionPrompt(Interactable->GetInteractionText());
                return;
            }
        }
    }
    
    // 상호작용 가능한 오브젝트 없음
    CurrentInteractable = nullptr;
    HideInteractionPrompt();
}
```

**감지 거리:** 200cm (기본)

---

### 상호작용 실행 (E키)

```cpp
void AHamoniaCharacter::InteractPressed()
{
    if (!CurrentInteractable) return;
    
    IInteractableInterface* Interactable = Cast<IInteractableInterface>(CurrentInteractable);
    
    if (Interactable && Interactable->CanInteract(this))
    {
        Interactable->Interact(this);
    }
}
```

## 🔷 주요 상호작용 오브젝트

---

### 1️⃣ 문 (Door)

**기본 문 열기 메커니즘**

```
E키 입력
    ↓
조건 체크 (열쇠, 퍼즐 완료 등)
    ↓
문 열림 애니메이션
    ↓
통과 가능
```

**조건:**
- 퍼즐 완료
- 특정 아이템 소지
- 타자기 패스워드 입력

---

### 2️⃣ 키패드 / 베리타스 회로

**UMG Widget을 띄우는 메커니즘**

```cpp
void AInteractableMechanism::HandleWidgetInteraction(AActor* Interactor)
{
    if (MechanismType == EMechanismType::Widget)
    {
        // Widget 생성
        UUserWidget* Widget = CreateWidget<UUserWidget>(GetWorld(), WidgetClass);
        Widget->AddToViewport();
        
        // 입력 모드 변경
        APlayerController* PC = Cast<APlayerController>(Interactor->GetInstigatorController());
        PC->SetInputMode(FInputModeUIOnly());
        PC->SetShowMouseCursor(true);
    }
}
```

**위젯 타입:**
- 베리타스 회로 (한붓그리기)
- 타자기 (키보드 입력)
- 힌트 프레임 (도면도)

**📖 상세 보기:** [베리타스 회로 →](./System/Puzzle/베리타스_회로.md)

### 3️⃣ 퍼즐 오브젝트

**들고 다니는 퍼즐 오브젝트**

거울, 반사패널, 분광기 등의 퍼즐 오브젝트입니다.

```cpp
// UPuzzleInteractionComponent
class UPuzzleInteractionComponent : public UActorComponent
{
public:
    // 줍기
    UFUNCTION(BlueprintCallable)
    bool PickUp(AActor* Picker);
    
    // 놓기
    UFUNCTION(BlueprintCallable)
    bool PutDown(FVector Location, FRotator Rotation);
    
    // 받침대에 배치
    UFUNCTION(BlueprintCallable)
    bool PlaceOnPedestal(APedestal* Pedestal);
};
```

**상호작용 흐름:**
```
E키 (오브젝트) → 줍기 → 들고 이동
    ↓
E키 (받침대) → 받침대에 부착
    ↓
R키 → 밀기
E키 회전 → 45° 회전
```

**📖 상세 보기:** [오브젝트 파밍 →](./System/Player/오브젝트_파밍.md)

### 4️⃣ 받침대 (Pedestal)

**퍼즐 오브젝트를 부착하는 플랫폼**

```cpp
UCLASS()
class APedestal : public AActor, public IInteractableInterface
{
    GENERATED_BODY()

public:
    // 오브젝트 배치
    UFUNCTION(BlueprintCallable)
    bool PlaceObject(AActor* Object);
    
    // 오브젝트 제거
    UFUNCTION(BlueprintCallable)
    AActor* RemoveObject();
    
    // 밀기 (R키)
    UFUNCTION(BlueprintCallable)
    bool Push(FVector Direction);
    
    // 회전 (E키)
    UFUNCTION(BlueprintCallable)
    void Rotate(float Degrees = 45.0f);
};
```

**그리드 시스템:**
- 그리드 단위로만 이동
- 벽이나 다른 받침대에 막힘
- 부착된 오브젝트와 함께 회전

**📖 상세 보기:** [받침대 시스템 →](./System/Pedestal/받침대_시스템.md)

```
Player Tick
    ↓
Raycast (매 프레임)
    ↓
Hit Interactable?
    ├─ Yes → Show Prompt
    └─ No → Hide Prompt
    ↓
E Key Pressed?
    ├─ Yes → Execute Interact()
    └─ No → Continue

    ├─ Object → Pick Up
    └─ Pedestal → Attach/Detach
```

## 🔧 주요 컴포넌트

### InteractionSphere (선택적)

일부 오브젝트는 Sphere Collision을 사용합니다.

```cpp
UPROPERTY(VisibleAnywhere)
USphereComponent* InteractionSphere;

void BeginPlay()
{
    InteractionSphere->OnComponentBeginOverlap.AddDynamic(
        this, &AInteractableMechanism::OnInteractionSphereBeginOverlap);
}
```

**사용 예:**
- Unia (대화 범위)
- 특정 트리거 (튜토리얼)

## 🎮 입력 처리

### Enhanced Input Mapping

```cpp
// Input Actions
UPROPERTY(EditAnywhere)
UInputAction* InteractAction;       // E키

UPROPERTY(EditAnywhere)
UInputAction* PushAction;           // R키

UPROPERTY(EditAnywhere)
UInputAction* RotateAction;         // E키 (회전 모드)

// Binding
void AHamoniaCharacter::SetupPlayerInputComponent(UInputComponent* PlayerInputComponent)
{
    UEnhancedInputComponent* EnhancedInput = Cast<UEnhancedInputComponent>(PlayerInputComponent);
    
    EnhancedInput->BindAction(InteractAction, ETriggerEvent::Triggered, 
        this, &AHamoniaCharacter::InteractPressed);
    
    EnhancedInput->BindAction(PushAction, ETriggerEvent::Triggered, 
        this, &AHamoniaCharacter::PushPressed);
}
```
